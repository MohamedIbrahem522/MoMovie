# 🎬 MO Movie App

## 📌 Overview
A modern movie discovery web app built with Next.js that fetches real-time movie data and provides a smooth browsing experience.

## ✨ Key Features
- 🔎 Real-time movie search
- 🔥 Trending movies section
- 📄 Detailed movie pages
- 📱 Fully responsive UI

## 🛠️ Tech Stack
⚛️ Next.js · ⚛️ React.js · 🎨 Tailwind CSS · 🌐 API Integration
